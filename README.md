# MIX STUDIO 0.7 / Private Vocal Studio

## GitHub / Cloudflare版（標準DSP）
1. ZIPの内容をPrivate GitHubリポジトリのルートへアップロード。
2. Cloudflare Pagesに接続。ビルド `npm run build`、出力 `dist`。Node.jsとnpm依存関係のインストールが必要。
3. Secret `ACCESS_PASSWORD` に指定の4桁PIN、`SESSION_SECRET` に32文字以上の独立したランダム文字列を設定。
4. D1データベースを作成し `setup/schema.sql` を実行、PagesのD1 binding `AUTH_DB` を設定。Previewにも設定するか無効化。
5. デプロイ。認証はサーバー側。15分の固定時間枠に全利用者合計5試行（成功を含む）。4桁PINは弱く、第三者によるロックアウトもあり得るためCloudflare Access併用推奨。

GitHub Pages単体では認証が動作しません。音源をCloudflareへ送信しません。

## WindowsローカルAI版（同じ操作画面）
- Python 3.10 (64bit)、Node.js/npm、NVIDIAドライバを事前にインストール。Demucsで必要に応じてFFmpegもPATHに追加。
- ZIPを展開し `local/install.bat` を実行。PyTorch CUDA 12.1版とモデル用ライブラリをインストールします。GPUを利用できない場合は音程・分離がCPU動作になります。DeepFilterNetはCPU動作です。
- `local/start.bat` を起動して指定の4桁PINを入力。ブラウザで http://127.0.0.1:8765 を開き、ユーザー名 `studio` と同じPINで認証。PINはファイルに保存しません。終了は端末を閉じる。ブラウザのBasic認証はブラウザ終了まで残る場合があります。
- 初回処理でモデルのダウンロードが必要になることがあります。録音データは外部サービスに送信されません。サーバーはループバックにのみバインド。LANやインターネットに公開しないでください。
- GitHub版にローカルAIを直接接続するのではなく、同じ画面をPC内で開く方式です。

## 操作と機能の範囲
- 音源を読み込み、プリセットを選択して自動MIX。詳細設定には音量、EQ、圧縮、低域カット、リバーブ、ディレイ、パン、高域抑制（動的ディエッサーではない）を搭載。
- AI音程推定: torchcrepe (CREPE tiny) で基本周波数を推定し、キーと強度に応じてDSPで波形補正。音程補正・ハモリは単音向け、フォルマントの厳密な維持やコード進行解析は未対応。
- AIノイズ抑制: DeepFilterNet。話し声向けのモデルで歌唱の音質を損なう可能性あり。弱設定から試す。
- AI音源分離: Demucs htdemucsで歌声・伴奏を個別にWAV保存。
- タイミング: ブラウザ版は開始位置推定。ローカル版は同じ歌のガイド歌唱に対してchroma DTWと区間タイムストレッチ。学習済みタイミングモデルではありません。合わない曲は拒否する場合があります。原曲から歌声分離してからガイドに指定する。補正WAVをボーカルとして読み直す。
- 原曲参考MIX: 分離ボーカルの明るさ・ダイナミクスを既存EQ/圧縮に反映する方式。完全再現ではありません。
- 日本語指示: 定型語句に基づく設定調整（LLMなし）。
- 追加ボーカル: 同じ開始位置で複数ファイルを読み込み、固定の自動音量で合成。個別トラック編集は未対応。
- マイク録音: HTTPSまたはlocalhostで許可して使用。伴奏との同期録音ではないため開始位置の調整が必要。
- WAV / MP3: WAV 16bit 44.1kHz stereo、MP3はlamejs 192kbps。ライブラリ取得失敗時は同梱のFFmpeg変換バッチも使用可。
- プロジェクト: 音源・追加ボーカル・参考音源・設定を .mixstudio に保存。出力は再MIX。ガイド選択は保存しません。
- 音圧調整はピーク正規化。LUFS規格準拠のマスタリングは未対応。
- 固定の曲長制限はないがメモリやPC能力に依存。ローカルAPIはリクエスト上限512MiB、DTWは16000フレーム上限。
